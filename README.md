BLACKFORGE
────────────────────────────────

Adversary Simulation & Detection Lab

A self-hosted AWS cyber range designed to
study offensive security, defensive monitoring,
network security, and incident response.

## Objectives

🔴 Red Team
- Reconnaissance
- Exploitation
- Privilege escalation
- Pivoting
- Lateral movement

🔵 Blue Team
- Logging
- Detection engineering
- Threat hunting
- Incident response

🟣 Purple Team
- Attack replay
- Detection validation
- Control improvement
- Retesting
